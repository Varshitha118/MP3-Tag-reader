# MP3 Tag Reader 🎵

A simple and efficient C-based application to read and edit MP3 metadata such as title, artist, album, year, and genre.

## 🚀 Features
- View MP3 tag details
- Edit title, artist, album
- Modify year and genre
- Command-line interface

## 🛠️ Technologies Used
- C Programming
- File Handling
- Modular Programming

## ▶️ How to Run
```bash
gcc *.c
./a.out sample.mp3
